# 2026-03-13 线索转化实施计划

## 目标

在现有询盘邮件归因基础上，补齐网站转化、归因数据入库与后台线索状态流，为后续人工回传打基础。

## 实施方向

### 任务一：扩展数据库字段

- 为 `contacts` 与 `inquiries` 增加线索状态、归因字段与基础地理字段
- 增加对应迁移文件与迁移日志

### 任务二：改造数据库读写

- 保存联系表单与询盘时同时写入归因数据
- 增加后台线索查询与状态更新函数

### 任务三：改造表单接口

- 在保存前统一整理归因与地理信息
- 在成功响应中返回前端埋点需要的上下文

### 任务四：补齐网站转化事件

- 复用现有埋点加载逻辑
- 仅在提交成功后触发网站转化事件

### 任务五：补齐后台线索接口

- 提供统一线索查询
- 支持状态流转与重复操作幂等

### 任务六：改造后台线索页面

- 去掉占位数据
- 展示来源、访问路径与状态信息
- 提供线索状态操作

### 任务七：验证与记录

- 执行 `pnpm lint`
- 执行 `pnpm type-check`
- 将限制与后续事项写入经验文档
