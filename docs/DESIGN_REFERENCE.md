# 设计基线

## 视觉方向

- 主色保持暖金与石色系
- 深色区块以石黑色为主
- 整体风格偏稳重、目录型、展示型
- 不主动引入与当前气质冲突的高饱和配色

## 字体与层级

- 标题使用衬线风格
- 正文使用无衬线风格
- 重点信息通过字号、字重与留白拉开层级

## 间距规则

- 外层容器继续使用统一页面宽度
- 主要区块保持较大上下留白
- 卡片之间的间距保持一致，不要随意压缩

## 组件风格

- 按钮保持圆角、清晰对比和明确主次关系
- 卡片保持浅边框与轻阴影
- 表单保持清晰输入边界与聚焦状态

## 占位资源规则

- 默认展示资源优先使用占位图
- 没有正式品牌资源前，不新增看起来像真实品牌的素材
- 所有对外可见文案与图片都应符合模板占位语境
