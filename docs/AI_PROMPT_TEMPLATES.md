# AI 开工提示词模板

这份文档是给你直接复制用的。

用法很简单：

1. 找到最接近你当前目标的场景
2. 把里面的【方括号内容】替换成你的信息
3. 直接发给 AI

统一原则：

- 默认继续保持 mock data
- 一次只改一块
- 改完后让 AI 给出本地检查地址
- 如果改了代码，让 AI 跑验证

## 模板 1：先让 AI 接手这个仓库

```text
这是一个网站模板仓库，请先阅读 README、docs/START_HERE.md、docs/AI_TEMPLATE_RULES.md。
继续保持 mock data，不要写真实客户信息，不要主动接真实第三方服务。
先告诉我：
1. 这个项目的关键入口文件有哪些
2. 前台和后台分别看哪些地址
3. 如果我要开始改站，最推荐的第一步是什么
```

## 模板 2：先改成某个行业的网站

```text
这是一个网站模板，请继续保持 mock data，不要写真实客户信息。
先把它改成一家做【行业/产品】的网站。
这一步只改品牌基础信息和首页，不要动后台登录、邮件、部署和数据库结构。
改完后请：
1. 说明改了哪些文件
2. 告诉我该看哪些本地地址
3. 运行必要验证
```

## 模板 3：首页改版

```text
继续保持 mock data。
现在只改首页，不要改后台逻辑，不要改数据库结构。
目标行业是【行业】，希望首页风格是【风格关键词】。
请优先调整：
- 首页主标题
- 副标题
- 首屏 CTA
- 首页分区顺序
- 首页核心卖点

改完后请告诉我应该检查的页面地址，并运行 type-check。
```

## 模板 4：产品页改版

```text
继续保持 mock data。
现在只改 /products 和相关产品展示组件，不要改后台逻辑。
请把产品页改成适合【行业/产品】的网站结构。
要求：
- 只保留适合该行业的分类结构
- 文案继续使用 mock data
- 不接真实数据库
- 如果缺图或缺描述，继续使用模板占位逻辑

改完后请告诉我该看哪些本地地址，并运行 type-check。
```

## 模板 5：替换品牌基础信息

```text
继续保持 mock data，但请把模板里的品牌方向改成【品牌方向/行业方向】。
这一步只改这些内容：
- src/lib/site-config.ts
- logo 文案或 logo 占位资源
- favicon 占位资源
- 首页品牌名称相关文案

不要改后台逻辑、认证、邮件、部署配置。
改完后请告诉我改了哪些文件，以及我该检查哪些页面。
```

## 模板 6：继续改前台，不动后台

```text
继续保持 mock data。
现在只改前台页面，不要改后台页面，不要改后台接口。
本次只处理这些页面：
- /about
- /services
- /contact

目标是让它们更适合【行业/品牌定位】。
请先复用现有组件和结构，不要做无关重构。
改完后请运行 type-check，并告诉我检查地址。
```

## 模板 7：开始接真实内容

```text
现在开始把模板里的 mock data 逐步替换成真实内容。
请不要一次性大改。
先告诉我你需要我提供哪些资料，再从最关键的入口开始改。
优先顺序：
1. site-config
2. logo 和 favicon
3. 首页文案
4. 联系方式

如果缺资料，请先停在 mock data，不要自行编造真实信息。
```

## 模板 8：准备上线前清查

```text
请帮我检查这个模板仓库里还有哪些 placeholder / mock data / example 信息没有替换干净。
重点检查：
- 品牌名
- 域名
- 邮箱
- logo / favicon
- 联系方式
- 前台对外文案

请按严重程度列出问题，并指出对应文件。
先不要直接修改，先给我 review 结果。
```

## 模板 9：只做代码清理，不改功能

```text
请检查当前仓库里哪些文件、组件或脚本已经没有被当前前台、后台和测试入口使用。
本次只做安全清理，不改功能、不改页面表现。
删除前请先确认引用关系，避免误删 Next.js 路由文件。
改完后请运行 type-check、lint 和测试。
```

## 模板 10：修一个具体问题

```text
请只修这个问题，不要顺手重构别的模块：
【把这里替换成具体问题描述】

要求：
- 保持 mock data 语义
- 优先最小改动
- 改完后说明原因
- 给出验证结果
```

## 你可以长期重复使用的固定前缀

如果你不想每次都重新解释，可以把下面这段作为固定开头：

```text
这是一个网站模板仓库。
默认继续保持 mock data，不要写真实客户信息，不要主动接真实第三方服务。
优先小步修改，先改前台和品牌基础信息，后改后台和部署。
改完后请告诉我该检查哪些本地地址；如果改了代码，请运行必要验证。
```
