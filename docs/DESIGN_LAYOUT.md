# 版式说明

## 当前模板基线

- 前台主要页面统一显示“可发布前自行替换的模板文案”
- 默认首屏使用占位场景图
- 默认站点标识图与浏览器图标均为占位资源
- 页面结构已适合后续替换正式品牌内容

## 主要页面说明

### 首页

- 首屏展示模板提示、主标题、主操作按钮
- 版块顺序为：首屏、精选产品、分类、优势、问答、引导区

### 产品列表页

- 使用分类卡片与产品卡片组合展示
- 默认价格、交期、MOQ 与卖点均视为占位内容

### 关于页

- 用于展示品牌故事、信任信息与评价结构
- 当前内容只用于版式验收

### 服务页

- 用于展示服务卡片、流程区块、问答与引导区
- 当前文案为模板占位说明

### 联系页

- 展示联系表单、模板联系方式与问答
- 当前联系信息不是生产环境信息

### 法务页面

- 当前内容仅作模板演示
- 发布前必须由真实负责人审核替换
