# 编码规则

## 基本原则

- 始终优先可读性与可维护性
- 只做当前任务明确需要的改动
- 避免重复实现，优先复用已有逻辑
- 修改代码时说明原因，不只描述做法

## 命名约定

- 变量：`camelCase`
- 常量：`UPPER_SNAKE_CASE`
- 组件：`PascalCase`
- 函数：`camelCase`
- 组件文件：`PascalCase.tsx` 或 `PascalCase.jsx`
- 工具文件：`camelCase.ts` 或 `camelCase.js`

## 前端约束

- 未经明确要求，不主动改动已确认的版式与视觉层级
- 继续沿用当前暖色与石色系视觉
- 所有对外文案默认保持模板占位语境

## 文档约束

- 代码改动后同步更新对应文档
- `docs/` 中的说明必须与当前代码行为一致
- 不把真实密钥、真实域名或真实客户信息写进文档

## 安全约束

- 不提交 `.env`、密钥、密码或其他敏感信息
- 删除文件、推送远端、重写历史前先确认
