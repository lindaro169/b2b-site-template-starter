# 项目背景

## 项目定位

这是一个可复用的模板站点，用于演示目录展示、询盘收集、内容管理和后台配置流程。当前仓库中的前台内容已经统一清洗为模板占位信息。

## 当前约束

- 前台主要页面默认统一为“可发布前自行替换的模板文案”
- 所有品牌名、域名、邮箱、账号、产品图与描述都视为占位值
- 文档、说明与部署配置不能假定任何真实公司背景

## 目标使用者

- 需要快速改造成企业展示站或目录站的开发者
- 需要保留后台、询盘、博客与部署骨架的团队
- 需要先用占位内容验收版式，再替换正式资产的业务方

## 核心能力

- 首页、产品页、关于页、服务页、联系页、法务页
- 产品目录与产品详情
- 联系与询盘表单
- 博客与后台管理
- Cloudflare Workers、D1、R2 部署

## 发布前替换清单

- `src/lib/site-config.ts`
- `.env.local`
- `.dev.vars`
- `wrangler.jsonc`
- `public/logos/template-logo.svg`
- `public/favicon.svg`
- 所有产品占位图与产品文案
